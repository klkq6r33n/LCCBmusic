Jukebox LimbusCompany - optional fonts
=====================================

This folder contains optional, freely redistributable CJK fonts:

  NotoSansJP-Variable.ttf   (Japanese / CJK)  SIL Open Font License 1.1
  NotoSansSC-Variable.ttf   (Simplified Chinese / CJK)  SIL Open Font License 1.1
  NotoSansJP-OFL.txt     licence text
  NotoSansSC-OFL.txt     licence text

Installation / 安装方法
-----------------------

Windows:
  1. Right-click the .ttf file -> "Install" (or "Install for all users").
  2. Restart ULTRAKILL.
  3. The mod automatically prefers "Noto Sans JP" / "Noto Sans SC" when they
     are installed, so Japanese / Chinese lyrics get complete glyph coverage.

中文：
  1. 右键 .ttf 文件 -> 安装（或“为所有用户安装”）。
  2. 重启 ULTRAKILL。
  3. mod 会自动优先使用已安装的 Noto Sans JP / Noto Sans SC，补全日文/中文字形。

ULTRAKILL font
--------------

The official ULTRAKILL Latin font is not redistributed here. Install
greycsont's font mods (Fffffff / FNT_font_no_tsubasa) on Thunderstore if you
want the game-exact font; the mod already uses the game/panel font whenever it
is available.

ULTRAKILL 官方英文字体不随包分发。需要官方字形时，请在 Thunderstore 安装
greycsont 的字体 mod（Fffffff / FNT_font_no_tsubasa）；mod 本身会优先使用
游戏面板字体。
